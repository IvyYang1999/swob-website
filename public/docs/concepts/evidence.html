EVIDENCE

知道什么，和推断什么，必须分开。

AI 工具保存的数据格式、完整度和语义不同。Swob 的可信度来自保留差异，而不是把所有来源压成看似一致的答案。

来源事实可解释重建启发式信号

三层证据

来源报告

由 harness 明确保存的 ID、时间、模型、用量、父子关系或工具事件。仍需确认字段语义和版本。

确定性重建

从多个累积计数取 delta、从已知路径恢复关系等；规则应可复现并保留输入证据。

启发式推断

反模式、摩擦、相似关系等解释性信号。它们指出复查点，不应被表述成客观事实。

能力状态

状态 含义 应该怎么用
可用 当前适配器和证据覆盖该能力 仍结合来源与版本说明
实验 依赖特定版本、反向解析或样本仍有限 适合验证，不适合强承诺
不可用 来源没有可信字段，或当前未实现 保持空缺，不用估算冒充事实
不适用 能力在该来源没有对应语义 不要拿来做横向排名

四条不越过的线

  • 没有权威 token 时，不使用 字符数 / 4 伪造用量。
  • 打开 App 或工作区，不表述成恢复到了指定历史会话。
  • 派生 Markdown、索引和报告不取代只读的原始会话真相源。
  • 未来方向、current main 和公开稳定版必须分层标注。

看到异常数字时

  1. 确认统计母集

    日期、来源、项目、可用性排除是否一致。

  2. 确认字段来源

    是 provider 报告、Swob delta 重建，还是估计规则。

  3. 下钻到单条会话

    检查原始事件、完整 transcript 与数据质量提示。

  4. 保留“不知道”

    若证据不足，正确结果是 unavailable，而不是一个好看的数字。
