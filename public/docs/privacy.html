PRIVACY

本地优先，不等于永不联网。

Swob 的会话读取、Library、索引和主要分析在本机完成。网络动作应当有明确目的和触发条件；可选 AI 洞察会把样本发送给你配置的提供商。

源目录只读Library 由你选择显式网络边界

Swob 读取什么

  • 你启用的 AI 工具在本机保存的会话目录、数据库或配置元数据。
  • 读取用于发现、解析、建立关系和判断 Resume 能力；原始真相源保持只读。
  • 排除来源意味着不扫描该来源，也不为其生成 Library 派生副本。

Swob 写入什么

LIBRARY

会话包与 transcript

保留可读 Markdown、派生元数据和恢复所需的本地记录。

INDEX

搜索与统计索引

支持正文检索、来源/项目筛选和本地聚合分析。

ORGANIZATION

组织状态

文件夹、Lens、标题、Profile、设置与可撤销事务记录。

Library 放在同步盘时

iCloud 或其他同步服务会按其自己的规则把 Library 复制到云端和其他设备。那仍是“你选择的存储”，但不再是仅存在单机的副本。

什么时候会联网

动作 触发 发送什么
更新检查 / 下载 应用启动、设置或下载操作 版本与发行请求；不需要上传 transcript
查询 SSH 公网地址 你显式点击查询 向公网 IP 服务发出普通网络请求
可选 AI Insights 配置提供商并明确确认 报告样本或会话片段发送给所选 AI 提供商
Resume / SSH / 外部打开 你点击或执行命令 按目标工具或主机协议发起连接

分析与遥测

在已审阅的桌面源码口径中，Swob 不上传产品使用分析、广告标识符或整条会话遥测。官网使用 Plausible 统计页面访问和下载点击；这与桌面应用的本地会话数据是两条边界。

脱敏能做什么，不能做什么

  • 派生 transcript 可以按规则隐藏常见凭据形态，分享前也应继续人工检查。
  • 自由文本、截图、路径、附件和工具输出仍可能包含姓名、项目名、token 或业务秘密。
  • 过滤不能保证所有秘密都被识别；AI Insights 前的确认不是形式按钮。
  • 不要把原始会话、.env、cookie、私钥或完整日志直接用于公开演示。

删除与保留

删除 Swob 派生数据、删除原客户端会话和从同步盘移除文件是不同操作。先确认目标、备份和同步影响；“重建索引”不应该删除唯一 transcript，“隔离重复项”也不等于永久删除。
