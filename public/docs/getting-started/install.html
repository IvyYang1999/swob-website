5 分钟找到第一条历史会话。

目标只有一个：打开一条真实会话，并用一句原文再次找到它。

macOSWindows x64 Beta约 5 分钟

1. 安装并打开 Swob

从官网或 GitHub Releases 下载与你的平台匹配的安装包。

  • macOS： Apple Silicon 与 Intel 安装包不要混用；拖入 Applications 后再启动。
  • Windows： 当前仅提供 x64 Beta，来源和 Resume 能力少于 macOS。
  • 系统拦截时，先核对下载来源和版本，不要直接绕过安全提示。

2. 选择 Library 和来源

首次启动时选择一个由你控制、已有备份的位置作为 Library。然后只启用你实际使用的会话来源。

Library 保存什么

Library 保存 Swob 生成的 transcript、索引和整理信息。关闭某个来源意味着不扫描它，不只是暂时隐藏。

3. 打开一条熟悉的会话

扫描完成后，先选最近使用、内容熟悉的一条会话。

只核对三项：

  • 来源和项目是否正确。
  • 时间是否大致吻合。
  • 正文是否包含你记得的内容。

Compact 适合快速阅读；需要工具参数和完整上下文时再切到 Full。

4. 用一句原文再次找到它

按 ⌘K（Windows 为 Ctrl+K），输入一段你记得的标题、项目名或正文。

成功状态： 搜索结果能打开刚才那条会话。搜不到时，先确认你用的是正文搜索还是元数据搜索，再进入排障。
