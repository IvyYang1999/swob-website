第一次成功只需要四步

  1. 安装 Swob，选择一个由你控制的 Library。
  2. 只启用你实际使用的会话来源。
  3. 打开一条内容熟悉的历史会话。
  4. 用一句原文再次找到它。

完成标准

你能打开一条真实会话，并用一句原文再次找到它。做到这一点，Swob 的核心价值已经可用；Resume、AI、CLI 和 Insights 都可以稍后再学。

使用前只需确认两件事

  • 你的工具支持什么： 能读取会话，不一定也支持正文搜索、用量或 Resume。查看来源支持 →
  • 数据会去哪里： 核心 Library 在本地；只有更新检查、SSH 和你主动触发的 AI 调用会使用网络。查看隐私边界 →

用熟以后再扩展

整理会话、Insights、Swob CLI、SSH 和全局 Agent 都是后续能力，不是首次使用的前置条件。

整理会话 → · 查看 Insights → · 使用 CLI → · 启用 AI / Agent →

先找到要继续的会话

在主窗口按 ⌘K 聚焦搜索框，输入消息中出现过的独特词语，再核对匹配片段、来源、项目与时间。主窗口搜索已建立索引的消息正文；无法解析正文的来源不代表可以全文搜索。

例如在虚构的 sample-shop 项目中讨论过 redirect，可以先搜 redirect，再打开结果确认上下文。独立 Spotlight 窗口还支持按项目和来源寻找候选；⌘Enter 在 Swob 中打开阅读，Enter 或点击结果会尝试 Resume。完整步骤见 English quick start。

1. 下载与安装

  1. 下载当前稳定版

    从官网或 GitHub Releases 下载与你 Mac 芯片对应的 DMG。稳定版和 current main 的功能边界以官网标注为准。

  2. 核对公开安装包

    当前官网提供 v1.3.1。安装包与发布说明以官方 GitHub Releases 为准；不要从不明镜像下载。本文部分说明面向开发版，界面和功能可能与稳定版不同。
