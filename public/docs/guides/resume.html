RESUME

继续一条历史会话。

从 Swob 选择会话和打开方式。目标工具出现这条会话的上一轮内容，才算 Resume 成功。

版本边界

本页保留开发版说明。官网公开安装包仍为 v1.3.1，较新的来源和客户端支持不一定包含在安装包中。针对 v1.3.1 的查找与续接步骤见 English Resume guide；能阅读、能打开 App 都不等于能恢复指定会话。

一分钟完成 Resume

  1. 打开一条内容熟悉的历史会话。 先核对来源、项目和上一轮内容。
  2. 点击 Resume，选择推荐入口。 有稳定 App 入口时可直接打开；否则使用终端。
  3. 在目标工具中核对上一轮内容。 只打开 App、工作区或新会话不算成功。

Resume 不可用时，先在下表核对来源，不要反复切换终端碰运气。

你的来源应该怎么打开

来源 推荐入口 结果要求
Claude Code 终端 claude --resume Claude Code 显示目标会话上一轮内容
Codex Codex App 或终端 App 打开同一 thread，而不是新建任务
Cursor Agent 终端 Agent 进入目标历史和工作目录
OpenCode 终端 OpenCode 进入指定 session
ZCode App（实验） 当前只保证打开工作区，不保证历史会话
其他来源 先看完整支持表 “实验”入口执行后必须人工核对目标

可以用哪些终端或软件

只要上表的“终端命令”是稳定或实验能力，就共用同一套终端设置，也支持自定义终端；ZCode、Grok Build 和 Trae 当前不适用。

平台 / 类型 当前支持
macOS Terminal.app、iTerm2、Ghostty、WezTerm、kitty、Alacritty
Linux Ghostty、WezTerm、kitty、Alacritty、GNOME Terminal、Konsole、foot、Xfce Terminal
Windows Beta Windows Terminal、PowerShell、cmd；当前 Resume 设置只显示 Claude Code 与 Codex
自定义终端 macOS / Linux 可填写包含 {{command}} 的命令模板，例如 otty {{command}}
不可直接执行 Warp 需要预配 Launch Configuration；Hyper、Tabby 没有稳定的外部命令入口

自定义模板缺少 {{command}} 时，Swob 会降级到系统终端，不会直接执行不完整模板。

失败时先判断是哪一层

  • ZCode App 只保证打开 App 或工作区，不保证跳到指定历史会话。
  • 点击 Resume 会先检查源文件。需要恢复时进入受控复活流程；“复制 Resume 命令”和 Resume Audit 不会写回源目录。
  • 终端没有打开：检查默认终端或自定义模板。
  • 工具打开但不是目标会话：检查来源、session ID、工作目录和入口能力。

Claude Desktop 仍是实验能力

必须先在设置开启“实验：导入到 Claude Desktop”；来源不是 Claude Code 或 session ID 格式不合法时会拒绝。
