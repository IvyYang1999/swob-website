FIND

记得内容，就应该找得到会话。

Swob 把“找一条记录”拆成两件事：按标题、项目、来源等元数据定位；按 transcript 正文找回那句你真正记得的话。

选择正确的入口

TOOLBAR

顶部搜索

在当前 Library 中搜索全部会话，并结合来源、项目、模型和日期筛选。

⌘⇧K

Spotlight

从桌面快速唤起会话选择器，键盘选择后 Resume 或在 Swob 中打开。

CLI

脚本搜索

swob search 查元数据；swob grep 用 FTS 查完整 transcript。

搜索与 grep 的区别

入口 查什么 适合
swob search 标题、项目、文件夹等元数据 已知会话大概身份
swob grep 已索引 transcript 正文，返回命中上下文 只记得对话里的一句话
界面全局搜索 会话与正文入口，结合筛选器 交互式缩小范围

更快找到目标

  1. 先输入最有辨识度的片段

    错误文本、函数名和完整短语通常比“那个设计讨论”更有效。

  2. 再按来源或项目收窄

    来源能力不同；只在支持正文索引的来源上期待 transcript 命中。

  3. 打开命中上下文

    搜索结果是入口，不是结论。回到前后轮次确认说话者、时间和工具证据。

当前边界

  • 当前是关键词/全文检索，不是语义向量搜索；改写后的同义表达可能不会命中。
  • 来源矩阵标为实验的搜索能力可能受来源格式和版本影响。
  • 未生成、损坏或尚未更新的 transcript 不会出现在完整正文索引中。
  • 搜索结果不会绕过已排除来源或 Library 数据边界。
