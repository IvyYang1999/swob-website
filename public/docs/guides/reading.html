三种视图

COMPACT

精简

保留对话主线，折叠冗长工具细节和中间事件。适合回顾“发生了什么”。

FULL

完整

展开 thinking、工具参数、工具结果和来源保留的事件。适合审计与排障。

MD

Markdown

以清洁 transcript 查看和复制正文，减少原始结构噪音。它是派生表示，不替代真相源。

长会话的阅读顺序

  1. 从标题、来源和项目确认身份

    标题可能被重命名；来源 ID、时间和项目路径更适合核对是否是目标会话。

  2. 用目录跳到关键轮次

    目录按消息与 compact 边界帮助定位，不必拖动一条数万行的原始日志。

  3. 先读 Compact，再按需展开

    遇到结论缺少依据时，切到 Full 查看工具调用、附件和中间事件。

  4. 在 Context / Audit 中交叉核对

    正文说明“说了什么”；右侧面板说明“用了什么上下文、如何执行、证据是否完整”。

Compact 边界是什么意思

部分 harness 会压缩早期上下文并继续同一条逻辑会话。Swob 用边界提示区分压缩前历史、压缩摘要和当前对话，避免把不同阶段拼成一段没有时间感的文本。

派生 transcript 不等于原始记录

Markdown 会移除格式噪音、统一消息结构，并可能折叠细节。需要取证或定位解析问题时，回到 Full 和来源证据。

高亮一段重要内容

在 Compact 或 Full 视图中选中一段正文，浮动按钮会把它保存为会话高亮。单次选择最多 2,000 个字符；高亮保存在 Swob 的会话元数据中，不写回原客户端 transcript。

  1. 选中一段完整语义

    尽量包含结论和必要上下文，不要只划一个模糊代词。

  2. 点击高亮按钮

    右侧 Outcomes / Details 中会出现高亮条目，目录也会显示相应标记。

  3. 从右侧跳回、复制或删除

    点击条目回到原轮次；复制只复制高亮文本，删除只移除 Swob 标注。

如果来源内容后来变化，Swob 会先按原文精确匹配，再尝试短前缀定位；定位不到时，高亮记录仍可能存在，但不会伪造新的正文位置。

复制、下载或导出选中的问答

顶部“多选”允许分别选择问题和回答。选中后可复制为 Markdown、下载 .md，或在启用 Share Templates Lens 时生成分享图。整条会话也可以直接复制或下载 Markdown。

  • 分享预览支持 Light、Dark、Minimal 主题和 via Swob 水印开关。
  • Session ID 与路径默认不包含在图片中；只有你显式打开才加入。
  • 长内容会自动分页，保存或复制前要逐页检查。
  • 内置秘密模式检测只提供警告，不能证明没有 API Key、内网地址、客户信息或私有路径。
  • Library Health 陈旧时，分享预览会显示提示；陈旧副本不应被包装成当前事实。

分享图不是证据脱敏器

默认隐藏字段和模式检测只能降低风险。真正的门禁仍是：只选择必要问答，并在导出前人工阅读每一页。

缺少内容时怎么判断

  • 来源本身可能没有保存 thinking、附件或完整工具结果。
  • 旧会话可能已被原客户端清理，只剩 Library 中的派生副本。
  • “不可用”应显示为空缺或状态，而不是由 Swob 猜测补齐。
  • 解析异常优先去 Library Health / Diagnostics；旧版本没有该入口时使用故障排查。
